# معمارية دفتري المحاسبي

## المرحلة 1 — نسخة العملاء التجريبية
الهدف الحالي هو بناء نسخة مستقرة للعملاء على Android وWindows من قاعدة Flutter واحدة.

### الوحدات
- المبيعات والكاشير
- المشتريات
- المخزون والباركود
- العملاء
- الموردون
- الصندوق والبنوك
- المصروفات
- الحسابات والقيود
- التقارير
- الإعدادات

### الاشتراك
طبقة الاشتراك موجودة في `lib/core/subscription/subscription_gate.dart`، لكن:

```dart
enforcementEnabled = false;
```

وبالتالي لا يُمنع أي مستخدم من التجربة.

## المرحلة 2 — لوحة الإدارة
ستكون تطبيقاً إدارياً منفصلاً للتحكم في:
- العملاء والمنشآت
- حالة الاشتراك
- الباقات
- التفعيل والإيقاف
- الأجهزة المسجلة
- التجديدات
- سجل العمليات

لن يُدمج حساب مدير الاشتراكات داخل تطبيق العميل.

## المرحلة 3 — تفعيل الاشتراكات
بعد انتهاء الاختبار:
1. إنشاء API مركزي للتحقق من الاشتراك.
2. تخزين ترخيص محلي موقّع للعمل دون اتصال لفترة سماح.
3. ربط الجهاز بالمنشأة.
4. تفعيل `enforcementEnabled`.
5. إضافة شاشة انتهاء الاشتراك والتجديد.

## ملاحظة المنصات
ملفات Android وWindows القياسية تُنشأ بواسطة Flutter SDK:

```bash
flutter create . --platforms=android,windows
flutter pub get
flutter run
```

ثم تُحفظ ملفات المنصات في المستودع.
