# دفتري المحاسبي

نظام محاسبة ومبيعات عربي مخصص للمطاعم والبقالات.

## الحالة الحالية
- نسخة العملاء التجريبية قيد البناء.
- الاشتراكات مجهزة معماريًا لكن **غير مفعّلة** أثناء فترة التجارب.
- الهدف: Android + Windows من قاعدة Flutter واحدة.
- الواجهة RTL وهوية دفتري المحاسبي.

## الوحدات في النسخة الأولى
- المبيعات
- المشتريات
- المخزون
- العملاء
- الموردون
- الصندوق
- المصروفات
- الحسابات والقيود
- التقارير
- الإعدادات

## التشغيل
بعد تثبيت Flutter:

```bash
flutter create . --platforms=android,windows
flutter pub get
flutter run
```

> لاحقًا ستضاف لوحة إدارة اشتراكات منفصلة للإدارة، بينما تبقى نسخة العملاء مفتوحة خلال مرحلة التجربة.
