# دفتري المحاسبي

نظام محاسبة ومبيعات عربي للمطاعم والبقالات، مبني بـ Flutter ليعمل على Android وWindows.

## النسخة الحالية 0.2
- واجهة عربية RTL وهوية دفتري المحاسبي.
- الشعار الرسمي مضمّن داخل التطبيق.
- قاعدة بيانات SQLite محلية.
- مبيعات وكاشير مع خصم المخزون.
- مشتريات مع زيادة المخزون.
- منتجات ومخزون وإضافة أصناف.
- عملاء وموردون.
- مصروفات.
- قيود محاسبية مزدوجة تلقائية للمبيعات والمشتريات والمصروفات.
- تقارير يومية أولية.
- الاشتراك موجود كطبقة معمارية لكنه **غير مفعّل أثناء التجارب**.

## التشغيل المحلي

```bash
flutter create . --platforms=android,windows --org com.diftiri.accounting
flutter pub get
flutter run
```

## البناء التلقائي

GitHub Actions يبني:
- APK Android release.
- Windows release.

بعد نجاح Workflow يمكن تنزيل الملفات من قسم Actions ثم Artifacts.

## الاشتراكات

`SubscriptionGate.enforcementEnabled = false` حالياً.

لوحة إدارة الاشتراكات وخدمة الترخيص المركزية هي المرحلة التالية بعد اعتماد نسخة العملاء.
